# OpenYoumiya Lab

OpenYoumiya 的学习与探索仓库。当前第一阶段：理清 HinaAI 应该做成什么、为谁解决什么问题，以及有哪些疑问和约束。

希望构建能够长期使用的 HinaAI，对 Agent Runtime / Infra 有技术兴趣。具体产品形态、核心场景与首版范围尚未确定。

## 从这里开始

- [探索原则](PRINCIPLES.md)：如何让行动和证据推动判断。
- [问题列表](QUESTIONS.md)：当前优先问题与暂存想法。
- [logs](logs/README.md)：实际做过的行动、发现与下一步。

每次选一个重要问题，做一个能获得信息的行动，留下简短记录，再决定继续、调整或暂缓。记录放在一处，通过链接引用。

## 当前下一步

找到一个希望 HinaAI 帮助完成的具体场景，了解现有方式有什么不足，再比较适合的产品形态。重启后话题连续性是暂存的候选技术问题。

## 决策与公开范围

需要审批的事项见 [代办清单](DECISIONS.md)。新技术设计与数据库字段方案仍需明确审批；普通阅读、场景调查与现有工具体验按实际问题开展。

公开记录使用通用角色称呼，保留项目事实和决策摘要，不包含个人标识、私人对话或凭据。

[许可方案](LICENSING.md)仍待确认，当前尚未作为仓库授权声明。
